# NavishAI

Turn your company's Support knowledge and history into tests for AI support systems.

NavishAI is rebuilding as a support evaluation lab. It is not a helpdesk or a customer-facing agent. The old implementation remains in Git history; its checks and deployment claims do not prove the new product.

Start with the [product authority](./documentation/PRODUCT.md), [architecture decision](./documentation/ARCHITECTURE.md), [domain](./documentation/DOMAIN.md), and [rebuild plan](./documentation/REBUILD_PLAN.md). Read [status](./documentation/STATUS.md) for what works and what remains, and [development](./documentation/DEVELOPMENT.md) for current setup and checks.

For self-hosting, see the [reset VPS CLI](./documentation/VPS_CLI.md) and [old-install cleanup](./documentation/LEGACY_UNINSTALL.md). Private proofs do not establish public-host acceptance.

Contributors follow [AGENTS.md](./AGENTS.md). Use existing dependencies, preserve tenant isolation and provenance, and keep expert decisions authoritative.
